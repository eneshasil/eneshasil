# Hi, I'm Enes 👋

### Data Engineer Associate

I build data pipelines and warehouses that turn messy source data into clean, trustworthy, analysis-ready tables. My background is in mathematics, so I care as much about *why the numbers are right* as about getting them to load.

## What I work with

- **Data modeling & warehousing:** medallion architecture (bronze / silver / gold), star schemas, slowly changing dimensions
- **SQL & PostgreSQL:** stored procedures, ELT orchestration, logging and error handling, data-quality checks
- **Python:** data analysis, visualization, graph/network analysis, machine learning from scratch
- **Applied AI:** LLM-based assistant prototypes
- **Currently learning:** Spark, Kafka, Airflow, dbt, Delta Lake, Docker, Terraform, AWS
- **Next up:** MLOps / LLMOps practices
